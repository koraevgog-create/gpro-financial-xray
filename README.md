# GPRO №1 — Финансовый рентген

Отдельный бесплатный инструмент для **диагностики** личных финансов: помогает увидеть текущее состояние, финансовую устойчивость и основные зоны внимания. Не заменяет отдельные сервисы GPRO для закрытия долгов, инвестирования, планирования бюджета или увеличения дохода.

**Сервис:** https://koraevgog-create.github.io/gpro-financial-xray/

## Текущий этап

- Принят владельцем: **уровень 6 из 9**, версия **0.6.1**.
- Следующий этап: **уровень 7**, в разработке.
- Рефакторинг: исходный одностраничный файл разделён на HTML, CSS и JavaScript **без изменения логики диагностики**.

## Структура

```text
/
├── index.html      — разметка и подключение ресурсов
├── css/
│   └── style.css   — стили и адаптивная/печатная версия
├── js/
│   └── app.js      — формы, расчёты и выводы
└── README.md       — документация
```

## Возможности

- Четыре шага ввода: доходы, расходы, долги и капитал.
- Расчёты денежного потока, долговой нагрузки, резерва и чистого капитала.
- Условный индекс финансовой устойчивости 0–100 (не кредитный рейтинг).
- Диагностические выводы с пояснениями и направлениями для дальнейшей работы.
- Адаптация для мобильных экранов и печать/PDF через браузер.
- Без регистрации и передачи введённых данных на сервер.

## Разработка и публикация

Откройте `index.html` в браузере или используйте GitHub Pages с публикацией из корня ветки `main`. Ссылки на CSS и JS относительные; сервер и сборщик не требуются.

**Принцип проекта:** один инструмент — одна функция. «Финансовый рентген» показывает состояние и проблемы, но не реализует функциональность специализированных инструментов из набора 46 сервисов.
