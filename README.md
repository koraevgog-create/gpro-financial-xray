# GPRO Tools — единая платформа из 46 сервисов

Один публичный GitHub Pages сайт, каждый инструмент открывается по собственной прямой ссылке. В интерфейсе сервисов нет каталога и ссылок на соседние инструменты. Это не техническое ограничение доступа: прямые адреса публичны.

## Адреса

- №1 **Финансовый рентген**: https://koraevgog-create.github.io/gpro-tools/financial-xray/ — версия 1.0.0, уровень 9 на финальной проверке.
- №2 **Мой бюджет**: https://koraevgog-create.github.io/gpro-tools/my-budget/ — версия 0.1.0, уровень 1 на проверке.

Корневая страница перенаправляет на финансовый рентген и не показывает каталог.

## Важные принципы

- **Отдельная функция для каждого сервиса**: финансовый рентген диагностирует, бюджет ведёт учёт операций.
- **Без аккаунтов и сервера**: данные бюджета хранятся только в localStorage того же браузера и устройства; при очистке хранилища данные теряются. Для сохранения используйте выгрузку CSV (экспорт не является автоматическим резервным копированием).
- **Переход в Telegram**: блок есть, реальная кнопка появится только после указания существующего адреса бота в `js/config.js` конкретного сервиса. Суммы не отправляются в Telegram.
- **GitHub Pages**: публикуется из корня ветки `main`. При переименовании репозитория проверьте настройки Pages, если новые адреса не открываются.
- **Центр контроля**: https://koraevgog-create.github.io/gpro-control-center/ — отдельный репозиторий.

Старые файлы `css/`, `js/`, `tests/` в корне пока сохранены для безопасной миграции; рабочая копия №1 находится в `financial-xray/`.
