# GPRO №1 — Финансовый рентген

Первый рабочий прототип (уровень 1/9). Отдельная интерактивная страница для первичной диагностики личных финансов.

## Запуск
Откройте `index.html` в браузере либо опубликуйте корень репозитория через GitHub Pages.

## Уже работает
- 4 шага ввода: доходы, расходы, долги, капитал.
- Расчёты месячного денежного потока, кредитной нагрузки, финансовой подушки, чистого капитала.
- Демонстрационный индекс устойчивости 0–100 (эвристика, **не кредитный рейтинг**).
- Контекстные выводы и первые практические шаги.
- Адаптация под мобильные экраны, печать в PDF через браузер.
- Без регистрации, аналитики, cookies и серверного хранения введённых данных.
